Things that bite

  • Subtract is its own signal now. In the old 3-bit encoding F[0] meant subtract. Now F[0] is funct3[0], which is 1 for sll. Anything that used F[0] (the b inverter, cin, the overflow formula) must use subtract.
  • Shift by b[4:0], not b. srai's immediate has bit 10 set (that's how it differs from srli), so shifting by all of b would shift by 1024 or more.
  • sra needs a signed operand, alone. Verilog takes signedness from the operands. Mix $signed(a) with anything unsigned in the same expression and >>> quietly becomes a logical shift.
  • sltu is ~cout. In subtract mode, cout = 1 means a ≥ b unsigned (no borrow). Connect the adder's cout port.
  • Branches use sub (1000) and read the flags. The output value is ignored. blt checks N ^ V, the same test slt makes.
